# Calculator.Gallery — Free Online Calculator Collection

**Official website:** https://calculator.gallery/

Calculator.Gallery is an online platform for practical calculators and digital tools covering mathematics, everyday calculations, finance, education, and productivity.

## Explore the live platform

Visit **[Calculator.Gallery — Free Online Calculators](https://calculator.gallery/)** for the online collection of tools.

## Repository contents

This repository publishes selected standalone calculator source code and frontend resources. The first published example is the Simple Calculator.

### Simple Calculator

Source: [`calculators/simple-calculator/index.html`](calculators/simple-calculator/index.html)

- Responsive HTML and CSS interface
- JavaScript arithmetic parser with standard operator precedence; it does not use `eval()`
- Addition, subtraction, multiplication, division, and remainder
- Calculation history saved in the visitor's browser using `localStorage`
- Delete individual history entries or clear all history
- Keyboard support

## Run locally

Open `calculators/simple-calculator/index.html` in a modern web browser. No build step or server is required.

## Project scope

This repository currently includes the Simple Calculator source code provided for publication. It is not a complete export of the Calculator.Gallery WordPress website. More calculators can be added in their own folders as their source code is extracted and reviewed.

## Security and privacy

Do not commit WordPress credentials, database exports, customer information, private API keys, payment secrets, or server configuration files.
